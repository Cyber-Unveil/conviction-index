# The Conviction Index™

**A founding document of human-anchored security.**

> Humans are not the weak link. They are the last defensible asset.

---

## What this is

The **Conviction Index™** is the measurable ratio between an organization's autonomous machine decisions and its governed human judgment — across every consequential moment where AI acts on its behalf.

It is a strategic instrument, not a compliance framework. It does not replace NIST AI RMF, ISO 42001, or other governance standards. It asks a different question:

| Compliance asks | The Conviction Index asks |
| :--- | :--- |
| *"Are we following the rules?"* | *"Have we kept the human?"* |

This repository hosts the **canonical public release** of the Conviction Index framework — the version of record for citation, discussion, and reference.
